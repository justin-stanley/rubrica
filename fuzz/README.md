# Fuzzing

The fuzz crate is its own workspace. `check.sh` builds every target on the pinned nightly, replays `regressions/` (inputs that once crashed a target) and runs each target on `corpus/spec`.

The `autolinks` and `differential` targets compare with upstream pulldown-cmark 0.13.6 and allow exactly one documented divergence: a table whose header row does not start with a `|` may interrupt a paragraph here, as in cmark-gfm, and not upstream. The same divergence reached through a lazy line is allowed too: a table inside a block quote whose header row is the quote paragraph's lazy continuation line (its source lacks the quote's `>` markers), as in `>|\n||\n>-|`, or inside a list item whose header row is the item paragraph's lazy continuation line (indented less than the item's content), as in `+ u\n|2\n  -|\n2|`, or inside a footnote definition whose header row is a lazy line (indented less than 4 columns past the `[`), as in `[^a]: x\n|y|\n    -|`; cmark-gfm opens that table, upstream never lets a table interrupt a paragraph through a lazy line. Inputs where our parse opens any of these tables are skipped by the comparison with tables on (`common.rs`); the allowance is listed in `docs/spec/deviations.md`.
