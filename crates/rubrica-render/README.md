# rubrica-render

The rendering core of [Rubrica](https://github.com/justin-stanley/rubrica): Markdown in,
sanitised HTML out, with the heading anchors, slugs and links that Wiki.js produces for the
same page. It is built on `rubrica-markdown`.

This is a library crate of the Rubrica workspace. Most readers want the `rubrica` program:

```sh
cargo install rubrica --locked
```
